לומדה למניעת פצעי לחץ – הוראות פתיחה

אפשרות א: פתיחה במחשב או בטלפון
1. חלצו את קובץ ה-ZIP.
2. מצאו את index.html.
3. פתחו אותו בדפדפן Chrome / Edge / Safari (ולא בעורך טקסט).
4. יופיע מסך הפתיחה עם התמונה והקרדיטים.

אפשרות ב: קישור לצפייה ישירה בלי הורדה בכל פעם
1. העלו את index.html למאגר GitHub ציבורי, בספריית השורש.
2. עברו ל-Settings > Pages.
3. בחרו Deploy from a branch, את ענף main ואת תיקיית /(root).
4. פתחו את כתובת האתר שמוצגת במקטע Pages.

הקובץ מכיל את התמונות והקוד באופן עצמאי ואין צורך בקבצים נוספים.
